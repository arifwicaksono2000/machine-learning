2. Feature Engineering

No Operation Columns Reason
1 Drop column customerID Unique ID per customer, no predictive value
2 Data type conversion (text to number) TotalCharges Stored as text; pd.to_numeric(errors='coerce')
3 Missing value imputation (fill with 0) TotalCharges 11 blank values, all with tenure = 0 (new customers not yet billed)
4 Feature selection gender, SeniorCitizen, Partner, Dependents, tenure, Contract, MonthlyCharges, TotalCharges Columns relevant to churn
5 Target encoding (label mapping) Churn No = 0, Yes = 1
6 One-hot encoding gender, Partner, Dependents, Contract Categories have no order; handle_unknown='ignore'
7 Standard scaling SeniorCitizen, tenure, MonthlyCharges, TotalCharges Same scale for all numeric features (needed for KNN)
